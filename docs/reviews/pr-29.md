## Findings

### P2-1: Snapshot validation accepts an even random-stream increment

Status: open.

File: `TheThingBelow.Core/Runs/RunSnapshot.cs:69-76`.

Trigger: Read a record whose snapshot gives one stream an even `increment`, such as `0x0000000000000000`, then replay it.

Expected: Reject the invalid stream position with the snapshot line and field context (T-2, G-18, D-259).

Actual: `RunSnapshot.Check` verifies stream order but not increment parity. `RunRecordText.Read` accepts the record. `RunState.Resume` then calls `Pcg32.FromSnapshot`, which throws a bare `ArgumentException` without the record line.

Consequence: A malformed record bypasses the record error contract, so its caller cannot report which line failed.

Correction: Validate that each increment is odd while the snapshot is checked, and preserve line 2 context when the reader rejects it.

Regression check: Add a test that changes a written snapshot increment to an even value and verifies that record reading or replay fails with `RunRecordException` naming line 2 and the increment. A disposable probe against the reviewed code accepted the text, then produced `System.ArgumentException: The increment 0 is even, and every PCG32 increment is odd.`
