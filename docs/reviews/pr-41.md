## Findings

### P1-1: The Menu action cannot close the menu

Status: fixed in `d6f5e00`.

File: `TheThingBelow.Game/scripts/Boot.cs:222`.

Trigger: Press the Menu key or button after the menu is open.

Expected: The input contract sends `IntentIds.CloseMenu` when the menu is open, as `InputActions.IntentOf` and D-162, D-650 require.

Actual at the earlier head: `ReadInput` always called `InputActions.IntentOf(action, false)`. The caller therefore sent `OpenMenu` for every Menu press. The `true` branch was unreachable from Game.

Consequence: A later menu cannot close through the input path, so the player cannot return from the menu with its assigned action.

Correction: Track the current menu-open state in the caller and pass that state to `IntentOf` for the Menu action. Update the state after the intent is made.

Regression check: `GameRunTests.TheMenuActionOpensTheMenuAndThenClosesIt` sends Menu twice through a real run and observes `OpenMenu` then `CloseMenu`. `InputIntentTests.NoCallSiteOfTheInputMapPassesAConstantMenuState` fails on the old code. Both pass.
