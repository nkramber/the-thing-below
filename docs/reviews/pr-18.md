## Findings

### P2-1: The local smoke target can accept a failed Godot build

Status: open.

File: `Makefile:41-43`.

Trigger: The Godot editor's build callback fails while `--build-solutions` returns exit code 0, as F-60 documents.

Expected: The local smoke check must report a build failure and stop before it can report success (T-2, D-117).

Actual: The Makefile checks only the process exit code, then starts the smoke session. The CI workflow separately reads the build log for `build callback failed`, which confirms that the process code alone does not establish build success.

Consequence: `make verify` can pass its smoke target without proving that the current Game assembly built.

Correction: Make the local smoke target inspect the editor log and fail on the known callback failure, using the same visible failure condition as CI.

Regression check: Cause the Godot build callback to fail while the editor returns 0. `make smoke` must fail before it reports a successful smoke session.

### P2-2: The review document line does not follow the required form

Status: open.

Commit: `0c402dd6611fdb49de79b604d7bf012e76557a40`.

Trigger: Read the PR description's Documents section before review publication.

Expected: Each Documents line starts with its row name and uses an allowed form. The pre-review `docs/reviews/` line names the review that the PR awaits (D-577, D-581).

Actual: The line reads `` `docs/reviews/`: This PR waits for the Codex review, which writes `docs/reviews/pr-<number>.md`. `` It does not start with `Changed:`, and it names a placeholder path instead of `docs/reviews/pr-18.md`.

Consequence: The Documents section does not satisfy the PR's required document gate.

Correction: Change the line to `docs/reviews/: Changed: docs/reviews/pr-18.md. This PR waits for this review.`

Regression check: Review the PR description and confirm the `docs/reviews/` line names the actual review path and follows the required form.
