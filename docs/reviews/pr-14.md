### P2-1: The completion gate rejects valid roadmap ownership

Status: open.

File: `.claude/skills/one-pr-one-session/SKILL.md:114-125`.

Trigger: Complete a PR whose description or roadmap names independent work that an existing later PR owns. PR #14 is one example: D-579 assigns machine enforcement to PR-3. The standard PR template also names the PR that creates each absent check under G-16.

Expected: D-577 and D-578 reject a document, handoff, review record, or merge record of the current PR that waits for another PR. They do not reject planned work that a roadmap already assigns to a different concern.

Actual: Completion line 8 says, `No line gives work to another PR.` The reviewer must check this line. The PR #14 description and the skill enforcement table give the machine work to PR-3, so the new gate rejects the PR that creates it. The standard PR template also gives each absent check to its creator PR.

Consequence: A compliant session cannot reach the hand-over point when its PR names a valid future owner. The rule conflicts with D-579, G-16, and the repository PR template.

Correction: Limit line 8 to the records and documents of the current PR. Use the same boundary in the Documents gate, the PR template, and the PR-3 exit tests.

Regression check: Apply the skill to two fixtures. A PR that defers one of its affected documents must fail. A PR that completes its own documents and names independent roadmap work in another PR must pass.
