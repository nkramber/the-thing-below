### P2-1: Escaped quotes bypass the scene text rule

Status: fixed in `70df5ef`.

File: `TheThingBelow.Tools/DetLint/SceneTextRule.cs:20-23`.

Trigger: A scene property contains a quote escaped with a backslash, for example `text = "Say \"hello\""`.

Expected: DL 9 reports every non-empty text or title value in a scene file (D-499, G-7).

Actual: At `f5eba68`, the pattern stopped at the escaped quote. The probe exited 0 with `0 finding(s)`. At `70df5ef`, the pattern reads an escaped character as one unit. The same probe reports one DL 9 finding and exits 1.

Consequence: Player-visible text with an escaped quote can remain in a scene file and bypass the string table rule.

Correction: The value pattern now reads an escaped character as one unit. The change is in `TheThingBelow.Tools/DetLint/SceneTextRule.cs`.

Regression check: `ATextValueWithAnEscapedQuoteFails` requires one DL 9 finding for the trigger. The test passes in the 187-test suite. Its assertion fails on the old behavior because the old pattern gives no match.
