### P2-1: The merged-PR stop rule blocks the transitional prompt

Status: open.

File: `.claude/skills/one-pr-one-session/SKILL.md:36`.

Trigger: The owner merges the bound PR and says `Merged PR #x`.

Expected: The session writes the transitional prompt for that PR, as D-601 requires.

Actual: Step 1 says to stop when the conversation holds a merged PR. Step 6 then requires the same session to write a prompt after that merge. The stop rule has no exception for that case.

Consequence: The session can stop before it writes the prompt that D-601 requires.

Correction: Add a narrow exception for the bound PR and the exact merge message, while keeping the stop rule for other merged PRs.

Regression check: Follow the written steps for a merged bound PR and the exact merge message. The instructions must permit the prompt and still block work for another merged PR.
