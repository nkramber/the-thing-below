### P2-1: The poll accepts a check that completes after the deadline

Status: open.

Open at: `87cf4cc`.

File: `.claude/skills/gitar-review/SKILL.md:219-224`.

Trigger: The check remains in progress at 15 minutes, completes after that deadline, and the next poll reads it before the loop exits.

Expected: D-1074 requires the session to stop and tell the owner when the check does not complete within 15 minutes.

Actual: The command handles any `completed` status before it checks whether `age` is at least 900 seconds. It also omits `completed_at` from the API result, so it cannot distinguish a timely completion from a late one.

Consequence: The session can accept a Gitar check that completed after the owner's 15-minute limit and continue the review loop.

Correction: Include the check's completion time and accept it only when it completed by the deadline. Otherwise print `not complete` and stop.

Regression check: Exercise command E with a check response whose `completed_at` is later than `push + 900`. It must print `not complete`, even when the response arrives before the next poll exits.
